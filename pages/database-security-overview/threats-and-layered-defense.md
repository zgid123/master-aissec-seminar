# Nguy cơ đa dạng cần phòng thủ nhiều lớp

::left::

### Các mối đe dọa phổ biến

<v-clicks>

- SQL Injection và network attacks
- Unauthorized access
- Privilege abuse và insider threats
- Misconfiguration
- Data leakage / exposure
- Data loss và ransomware

</v-clicks>

::right::

### Các biện pháp bảo vệ

<v-clicks>

- Authentication và access control
- Encryption at rest / in transit
- TLS, firewall và network isolation
- Backup & recovery
- Auditing & monitoring
- Principle of Least Privilege

</v-clicks>
